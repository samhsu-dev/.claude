# Punctuation

## Colon

- Write a colon only before: a list the lead-in announces; an explanation that specifies the preceding clause; an appositive naming what the preceding clause refers to.
- Never write a colon for a cause-effect link (write "because"), between two unrelated statements, or after a verb or preposition that governs the following text.
- One colon per sentence. The clause before the colon is a complete sentence.

## Semicolon

- Write a semicolon only between two independent clauses in parallel or contrast, or between list items that contain commas.
- Never write a semicolon for a directional relation (write "because", "but", "while").
- In every other case, write a period.

## Em-Dash

- Write a paired em-dash only around a parenthetical aside, at most once per paragraph.
- Never put a definition or the sentence's main content between em-dashes.
