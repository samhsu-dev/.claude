# TypeScript Task Management

TypeScript-specific task conventions. Extends global `docs/todo.md`.

---

## Quality Gate

The global task checklist uses `code/quality.md` Quality Workflow for lint and format, type check, import graph and tests.

## Conventions

- Design docs cited by relative path: `path/to/design.md`.
- Test tasks name the test file: `tests/<sub>/<module>.test.ts`.
- Implementation tasks reference `impl.md` for library findings.
